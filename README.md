# Mesh Area → Desmos

A Blender add-on that measures **surface area and edge length** of a whole mesh or just the selection, and exports the geometry to **Desmos 3D / 2D** for graphing.

It also counts unapplied Subdivision Surface and Mirror modifiers in the measurement.

- **Blender:** 4.2 or newer
- **Location:** 3D Viewport → Sidebar (N) → Mesh Area

## Install

1. Download `mesh_area_desmos.py`.
2. In Blender, open **Edit → Preferences → Add-ons**, choose **Install from Disk**, and pick the file.
3. Enable **Mesh Area → Desmos**.
